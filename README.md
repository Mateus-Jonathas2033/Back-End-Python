# Back-End-Python


<h4>
<p>
Projeto sobre uma aplicação em Python para alugar serviços de restaurantes diversos.<br>
A aplicação contará com um sistema dualidade cliente/empresa.<br>
Ou seja, no mesmo ambiente o cliente poderá contratar serviços, e a empresa poderá hospedar serviços e produtos.
</p>
</h4>
